# frontend

React 화면입니다. 백엔드(Spring, 기본 `http://localhost:8080`)와 통신합니다. 사진 썸네일과 추천 결과도 백엔드를 거쳐 받습니다(백엔드가 모델 서버를 부름). 호출할 API와 응답 형식은 [backend/README.md](../backend/README.md)의 API 절에 있습니다. 개발 서버 주소가 `localhost:5173`이 아니면 백엔드의 `j1.cors-origins`에 추가합니다.

## 화면

- **로그인:** 로컬 계정, 카카오·구글, 게스트 진입
- **내 큐레이션 보관함:** 저장한 묶음 목록과 상세. 결과 폴더가 없어졌으면 안내를 표시
- **앨범 선택:** 경로 입력, 추천/직접 선택 모드
- **초안 편집:**
  - 초안·미포함 묶음·원본 전체 탭
  - 같은 묶음 컷으로 교체, 추가·제외
  - 선택 수 표시 (9/10, 11/10에서도 편집 가능, 10/10에서 확정)
- **최종 확정:** 저장 경로와 여행 제목 입력, 완료 후 하이라이트 화면
- **평가 모드:** 과업 시간과 조작 횟수 기록
